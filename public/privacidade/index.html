Política de privacidade

Última atualização: 17 de novembro de 2026

Esta política explica como o GotaVértice trata informações quando você usa o aplicativo para acompanhar o consumo de água de uma residência. O serviço é mantido por Gabriel Lúcio de Araújo e o contato público do projeto está disponível no repositório GitHub.

Resumo: os dados da sua conta ficam no Firebase, não no GitHub. O acesso aos documentos do Firestore é limitado ao usuário autenticado correspondente ao próprio UID.

1. Dados tratados

Podemos tratar o e-mail, o identificador técnico da conta, o nome exibido pelo provedor Google quando você escolhe esse login, o nome da residência, o número de moradores e as leituras do hidrômetro informadas por você. O aplicativo também recebe informações técnicas mínimas necessárias para autenticação, segurança e funcionamento, como identificadores de sessão e registros de erro do provedor.

2. Para que usamos os dados

Usamos os dados para criar e autenticar sua conta, exibir o dashboard, calcular histórico e consumo, salvar a configuração da residência, permitir exportação e proteger cada conta contra acesso indevido. Não usamos as leituras para publicidade direcionada e não vendemos dados pessoais.

3. Onde os dados ficam

As contas usam o Firebase Authentication e os dados do aplicativo usam o Cloud Firestore. O código-fonte e as regras de segurança ficam no GitHub, mas os documentos dos usuários e as senhas não ficam no repositório. Senhas de contas de e-mail são gerenciadas pelo Firebase Authentication e não são salvas pelo aplicativo em texto puro.

4. Compartilhamento e provedores

O Firebase/Google processa os dados para fornecer autenticação, banco de dados, hospedagem e segurança da infraestrutura. O Google pode processar dados conforme seus próprios termos e políticas. O GotaVértice não compartilha dados com anunciantes. Podemos divulgar informações se houver obrigação legal válida ou para proteger o serviço contra abuso.

5. Segurança

Usamos HTTPS, Firebase Authentication e regras do Firestore que exigem autenticação e comparam o UID da sessão com o caminho do documento. O site também evita indexar o dashboard e as rotas de API. Nenhuma medida na internet é absoluta; se você identificar um problema, comunique-o pelo repositório GitHub antes de divulgar detalhes sensíveis.

6. Retenção, exportação e exclusão

Os dados permanecem enquanto a conta for necessária para usar o serviço ou até que você peça a exclusão. No dashboard, você pode exportar residência e leituras em JSON, limpar os dados da residência ou solicitar a exclusão completa da conta. A exclusão completa remove o documento do Firestore, as leituras e a conta do Authentication, quando a sessão tiver autorização recente.

7. Seus direitos

Você pode consultar, corrigir, exportar ou excluir os dados associados à sua conta. Para exercer um direito que não esteja disponível na tela, abra uma solicitação no GitHub Issues, sem incluir senha, token ou dados sensíveis.

8. Alterações

Esta política pode ser atualizada quando o aplicativo ganhar novos recursos. A data no início da página identifica a versão vigente. Mudanças relevantes serão descritas no repositório.

9. Contato

Para dúvidas sobre privacidade ou segurança, use o canal de issues do projeto. Não publique informações pessoais de terceiros em uma issue.
